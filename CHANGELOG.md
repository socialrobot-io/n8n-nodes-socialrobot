## [0.1.0] - 2026-08-16

### Added

- SocialRobot node with Post, Account, and Media resources.
- Post operations: Create, Get, Get Many, Delete, Reschedule.
- Account operation: Get Many.
- Media operation: Get Upload URL.
- SocialRobot API credential with API key and configurable base URL.
- Account resource locator with list search.
